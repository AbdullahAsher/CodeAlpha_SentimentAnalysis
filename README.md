# Product Review Sentiment Analysis

A Python project that analyzes the sentiment of product reviews using **Natural Language Processing (NLP)** and the **VADER Sentiment Analyzer** from the NLTK library.

The project classifies product reviews into three sentiment categories:

- Positive
- Neutral
- Negative

It also generates a summary CSV file and a visualization showing the sentiment distribution.

## Features

- Analyzes product review text using VADER sentiment analysis.
- Calculates a compound sentiment score for each review.
- Classifies reviews as Positive, Neutral, or Negative.
- Saves the analysis results to a CSV file.
- Generates a bar chart showing the distribution of sentiments.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- NLTK
